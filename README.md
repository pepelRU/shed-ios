# Shed for iOS

iOS-версия приложения **Shed** с расписанием колледжа для группы **ПР126** (корпус на Ленина, 24).
SwiftUI, минимальная версия iOS 26.0. Сборка — GitHub Actions, готовый unsigned IPA ставится в LiveContainer.

## Что умеет

- четыре вкладки: **Сегодня / Завтра / Неделя / Следующая**;
- вшитое двухнедельное расписание ПР126 (`LocalBaseSchedule`);
- загрузка опубликованных изменений с `oat.ru` — сайт на Blazor, поэтому страницы изменений рендерятся в `WKWebView` и только потом парсятся;
- **Дневник.ру**: кнопка «Войти» открывает официальную страницу в **Safari**, как обычный вход. Для того чтобы Shed читал расписание Дневник.ру, есть отдельная кнопка «Подключить в приложении» — встроенный вход с Safari user agent и всплывающими окнами ESIA. Приложение забирает только две cookie Дневник.ру и хранит их в Keychain;
- замены, переносы, добавленные занятия, изменённое время и отмены;
- подгруппы 1/2, отменённые пары скрываются;
- кэш последнего проверенного расписания и работа без сети;
- pull-to-refresh, прогресс текущей пары, перемены, статус актуальности;
- светлая, тёмная и системная темы, хаптика;
- фоновая проверка через `BGTaskScheduler` (насколько разрешит iOS);
- проверка обновлений по `update-ios.json` со ссылкой на новый IPA.

## Чего нет

- **Уведомлений** — по договорённости их не делаем.
- **Передачи cookie из Safari в приложение** — iOS не даёт приложению доступ к cookie Safari. Поэтому вход в Safari не подключает Дневник.ру к Shed: для этого нужен встроенный вход или серверный мост.
- **Моста в Telegram-бота** (VPS, SSH-ключ устройства). На iOS это требует регистрации нового ключа устройства на сервере; на расписание в приложении это не влияет.
- **Самообновления APK** — на iOS такого механизма нет. Приложение проверяет `update-ios.json` и открывает ссылку на новый IPA, который нужно импортировать в LiveContainer.

## Сборка через GitHub

1. Создай **публичный** репозиторий на GitHub (публичный = бесплатные macOS-минуты Actions).
2. Запушь проект:

   ```bash
   git remote add origin https://github.com/pepelRU/shed-ios.git
   git push -u origin main
   ```

3. Открой **Actions → Build IPA**. Сборка запустится автоматически.
4. После сборки открой **Releases → Latest build** и скачай `Shed.ipa` прямо с iPhone:

   ```
   https://github.com/pepelRU/shed-ios/releases/download/latest/Shed.ipa
   ```

5. В LiveContainer нажми **+** и выбери скачанный `.ipa`.

## Если хочешь поменять репозиторий обновлений

В `project.yml` найди `UpdateManifestURL` и замени `pepelRU/shed-ios` на свой репозиторий.
В `update-ios.json` лежит манифест версии:

```json
{
  "build": 2,
  "version": "1.1",
  "url": "https://github.com/pepelRU/shed-ios/releases/latest",
  "notes": "Что нового"
}
```

`build` сравнивается с `CFBundleVersion` установленного приложения.

## Структура

```
project.yml                     XcodeGen-описание проекта
Shed/
  App/                          точка входа, сервисы, background refresh, update checker
  Core/                         модели, календарь Омска, локальная база ПР126, настройки
  Data/                         парсеры oat.ru и Дневник.ру, кэш, merge, политики дат
  UI/                           SwiftUI-экраны
  Resources/Assets.xcassets     иконка и AccentColor
.github/workflows/build.yml     сборка unsigned IPA
update-ios.json                 манифест обновлений
```

## Технические детали

- Проект генерируется **XcodeGen** из `project.yml`, `.xcodeproj` в репозитории не хранится.
- Зависимость — только **SwiftSoup** (парсинг HTML).
- Все даты считаются в часовом поясе **Asia/Omsk**, как в Android-версии.
- Кэш — JSON в Application Support, cookie Дневник.ру — в Keychain.
- Bundle ID: `dev.shed.schedule`.
- Уведомления и VPS-мост намеренно не включены.

## Ограничения

- Первый запуск на GitHub и будет проверкой сборки: локального macOS/Xcode здесь нет.
- Приватный репозиторий = платные macOS-минуты (~$0.062/мин). Альтернатива — Codemagic, 500 бесплатных минут M2 в месяц.
- Если сайт колледжа изменит разметку, приложение покажет ошибку и продолжит работать на локальной базе.
